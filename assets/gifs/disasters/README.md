# Disaster GIFs Directory

This directory contains disaster-themed GIF animations for the T.U.L.O.N.G app.

## Required GIF Files:

1. **emergency.gif** - General emergency animation
   - Used in: Tutorial page 1 (Welcome), Splash screen rotation, Home screen sample alert, Disaster Demo screen
   - Recommended size: 300x300px or larger
   - Should show general emergency/alert animation

2. **fire.gif** - Fire emergency animation
   - Used in: Tutorial page 2 (Emergency Alerts), Disaster Demo screen
   - Recommended size: 300x300px or larger
   - Should show fire/flames animation

3. **earthquake.gif** - Earthquake animation  
   - Used in: Tutorial page 3 (Community Chat), Disaster Demo screen
   - Recommended size: 300x300px or larger
   - Should show ground shaking or earthquake effects

4. **flood.gif** - Flood animation
   - Used in: Tutorial page 4 (Emergency Contacts), Disaster Demo screen  
   - Recommended size: 300x300px or larger
   - Should show water/flooding animation

## Usage in App:

- **Splash Screen**: Rotating display of all four disaster types (emergency, fire, earthquake, flood)
- **Tutorial Screen**: Each disaster GIF appears on specific tutorial pages
- **Home Screen**: Sample emergency alert with GIF demonstration
- **Disaster Demo Screen**: Full-screen disaster animations with overlays
- **Emergency Alert Widget**: Reusable component for emergency notifications

## File Format:
- Format: GIF (animated)
- Optimization: Keep file sizes reasonable for mobile performance
- Transparency: Not required (will be displayed with overlays)

## Integration:
The app will automatically load these GIFs when available. If a GIF file is missing or fails to load, the app will display a fallback icon instead.
